Gestensteuerung für micro:bit (Teachable Machine)

  1. Modell auf teachablemachine.withgoogle.com trainieren und exportieren ("Export Model" → Tab "Tensorflow.js" → "Upload my model" → Link kopieren).
  2. Link unten einfügen und auf "Modell laden" klicken.
  3. micro:bit per USB anschließen (vorher mit microbit/main.py bespielt) und auf "micro:bit verbinden" klicken.
