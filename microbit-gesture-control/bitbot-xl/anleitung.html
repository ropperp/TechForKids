🤖 BitBot XL – Gestensteuerung

Kurzanleitung zum Einrichten und Starten. Für Hintergründe/Troubleshooting siehe die README.md im übergeordneten Ordner.

Wie das Ganze zusammenspielt

Webcam (Mac, Python) Sender-micro:bit BitBot-micro:bit ┌────────────────┐ USB ┌────────────────┐ Funk ┌───────────────────┐ │ gesture_reader │ ─────▶ │ funkt Kommando │ ────▶ │ steuert Motoren, │ │ .py │ Kabel │ weiter │ │ Lichter, Lautspr. │ └────────────────┘ └────────────────┘ └───────────────────┘

Welche Datei gehört wohin?

  • gesture_reader.py + requirements.txt → läuft als Python-Programm auf dem Mac (Webcam-Erkennung).
  • microbit-sender/main.py → auf den micro:bit, der per USB am Mac bleibt.
  • microbit-bitbot/main.py → auf den micro:bit, der auf dem BitBot XL sitzt.

Schritt für Schritt

  1. Python-Umgebung einrichten (einmalig, im Terminal in diesem Ordner): 
    python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
  2. Sender-micro:bit flashen: micro:bit per USB anschließen, auf python.microbit.org öffnen, Inhalt von microbit-sender/main.py einfügen, auf "Flash"/"Send to micro:bit" klicken. Zeigt danach ein Smiley 🙂.
  3. BitBot-micro:bit flashen: den micro:bit, der auf dem BitBot XL sitzt, kurz per USB anschließen, Inhalt von microbit-bitbot/main.py einfügen, flashen. Danach wieder auf den BitBot stecken, Batterien rein.
  4. Sender-micro:bit am Mac lassen und Port herausfinden: 
    python gesture_reader.py --list-ports
  5. Starten (fragt nach Geschwindigkeiten, Enter = Standardwert): 
    python gesture_reader.py --port /dev/tty.usbmodemXXXX
RADIO_GROUP (Standard 1) muss in microbit-sender/main.py und microbit-bitbot/main.py identisch sein. Mehrere Teams im selben Raum? Jedes Team braucht eine eigene Nummer.

Typische Probleme

  • Port nicht gefunden / falscher Port: micro:bit neu einstecken, erneut --list-ports ausführen – der Portname kann sich je nach USB-Anschluss ändern.
  • mediapipe Fehler beim Start: pip install "mediapipe==0.10.14" in der aktivierten .venv ausführen.
  • pip install -r requirements.txt bricht ab mit "Could not find a version that satisfies the requirement jaxlib": mediapipe verlangt jax/jaxlib, obwohl unser Skript das gar nicht braucht - auf manchen Macs gibt es dafür gerade kein passendes Paket. Workaround in der aktivierten .venv: 
    pip install --no-deps mediapipe==0.10.14
pip install numpy attrs flatbuffers "protobuf>=4.25.3,<5" absl-py sounddevice opencv-python pyserial
  • Kamera öffnet nicht: macOS-Kamera-Berechtigung fürs Terminal prüfen (Systemeinstellungen → Datenschutz & Sicherheit → Kamera).
